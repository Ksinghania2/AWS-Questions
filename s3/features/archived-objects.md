# Archived Objects

Archived objects are stored in low-cost archive tiers for long-term retention, compliance, and backup scenarios.

## When to use this
- Legal and regulatory retention
- Backup archives that are rarely accessed
- Historical data that should be preserved cheaply

## Key points
- Retrieval time is slower than standard or infrequent-access classes.
- Archive storage is ideal when data is rarely needed.
- Lifecycle policies often move data into archive tiers automatically.
