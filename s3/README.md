# S3 study notes

This folder now contains a categorized collection of S3 topic notes for AWS study, labs, and interview prep.

## Structure
- [buckets](buckets) for bucket design and naming topics
- [features](features) for advanced S3 capabilities and integrative services
- [s3 object overview](s3 object overview) for object-level concepts such as metadata, prefixes, and versioning
- [s3 security overview](s3 security overview) for access control, encryption, and governance
- [s3 storage classes](s3 storage classes) for storage class behavior and use cases
- [encryption](encryption) for encryption models and key-management patterns

## Suggested reading order
1. Start with the core bucket and object concepts.
2. Review the security and encryption guides.
3. Explore advanced features such as lifecycle, replication, and transfer acceleration.
4. Compare the storage classes and choose the most appropriate one for each workload.
