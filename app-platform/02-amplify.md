# AWS Amplify

Full-stack development platform.

## CLI
```bash
amplify init
amplify add auth
amplify add api
amplify push
amplify publish
```

## Q&A
**Q1: What is Amplify?** A: Full-stack platform. **Q2: Auth provider?** A: Cognito. **Q3: API types?** A: GraphQL (AppSync) and REST. **Q4: Deploy command?** A: `amplify push`. **Q5: Hosting features?** A: CI/CD, custom domains, SSL, CDN.
