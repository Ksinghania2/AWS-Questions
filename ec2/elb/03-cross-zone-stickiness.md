# Cross-Zone Load Balancing & Session Stickiness

## Cross-Zone Load Balancing
Distributes traffic evenly across all registered instances in all AZs.

| LB Type | Default | Description |
|---------|---------|-------------|
| ALB | Enabled | No additional cost |
| NLB | Disabled | Additional cost if enabled |
| CLB | Disabled | No additional cost |

```bash
# Enable cross-zone for NLB
aws elbv2 modify-load-balancer-attributes     --load-balancer-arn arn:xxx     --attributes Key=load_balancing.cross_zone.enabled,Value=true
```

## Session Stickiness (Session Affinity)
Routes requests from same client to same target.

```bash
# Enable stickiness on ALB target group
aws elbv2 modify-target-group-attributes     --target-group-arn arn:xxx     --attributes Key=stickiness.enabled,Value=true Key=stickiness.type,Value=lb_cookie Key=stickiness.lb_cookie.duration_seconds,Value=86400

# App cookie stickiness
aws elbv2 modify-target-group-attributes     --target-group-arn arn:xxx     --attributes Key=stickiness.enabled,Value=true Key=stickiness.type,Value=app_cookie Key=stickiness.app_cookie.cookie_name,Value=MyAppCookie Key=stickiness.lb_cookie.duration_seconds,Value=86400
```

## Q&A
**Q1: What is cross-zone load balancing?** A: Distributes traffic evenly across instances in all AZs.
**Q2: Is cross-zone enabled by default on ALB?** A: Yes, and no additional cost.
**Q3: What is session stickiness?** A: Routes same client to same target using cookies.
**Q4: What are the two types of stickiness cookies?** A: LB cookie (generated by ALB) and App cookie (custom).
**Q5: What is the max duration for stickiness?** A: 7 days (604800 seconds).
